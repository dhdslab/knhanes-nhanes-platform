# KNHANES + NHANES Evidence Reports — searchable with RAG

> The complete corpus of machine-generated, audited analysis reports for the study
> *"Map once, answer thousands: an audited AI infrastructure for national health evidence,"*
> together with a small **retrieval-augmented search tool** so that **anyone — not only a
> statistician — can ask a plain-language question and get the exact answer with a link to the
> source report.**

## What is in this repository

```
suppl/
  KNHANES/  association/<Outcome>/<Exposure>__<Outcome>_KNHANES.docx   (3,522 pairs)
            trend/<Outcome>__trend_KNHANES.docx                        (27)
            ml/<Outcome>__prediction_KNHANES.docx                      (27)
  NHANES/   association/<Outcome>/<Exposure>__<Outcome>_NHANES.docx    (3,956 pairs)
            trend/<Outcome>__trend_NHANES.docx                         (25)
            ml/<Outcome>__prediction_NHANES.docx                       (27)
  _manifest_association_KNHANES.csv   # every pair: estimate, 95% CI, p, FDR q, N, adjustment set
  _manifest_association_NHANES.csv
  _SUMMARY.txt
rag/                # the search tool (this README's "How to use")
```

Every report is self-contained (structured abstract, methods, the adjusted estimate with 95% CI
and FDR q, and a survey-weighted descriptive table). All statistics were computed deterministically
in R `survey` and scikit-learn; the language model only wrote prose and **never produced a number.**

## How to use (no expertise required)

### 1. Install
```bash
git clone <this-repo-url>
cd <this-repo>
pip install -r rag/requirements.txt
```

### 2. Build the search index (one time, a few minutes)
```bash
python rag/build_index.py
```
This reads every report in `suppl/` and builds a local search index. By default it uses TF-IDF,
which needs **no external service**. For better semantic search, install
[Ollama](https://ollama.com) (`ollama pull bge-m3 && ollama pull llama3.2`) and run
`python rag/build_index.py --backend ollama`.

### 3a. Ask questions in a web page (easiest)
```bash
streamlit run rag/app.py
```
A browser tab opens. Type a question in plain English and read the answer with links to the exact
source reports.

### 3b. …or from the command line
```bash
python rag/ask.py "Is uric acid associated with hypertension in NHANES?"
python rag/ask.py "odds ratio for BMI and diabetes" --survey KNHANES
python rag/ask.py "which model predicts metabolic syndrome best?" --type ml
```

**Example questions**
- `Is uric acid associated with hypertension?`
- `What is the odds ratio for waist circumference and diabetes in KNHANES?`
- `How well can we predict chronic kidney disease?`
- `What is the trend of diabetes prevalence?`

## How it works

1. **Index** — each Word report is parsed to text and stored with its metadata (survey, report
   type, exposure, outcome) and its exact file path.
2. **Retrieve** — your question is matched against the reports (TF-IDF, or bge-m3 embeddings via
   Ollama), optionally filtered by survey or report type.
3. **Answer** — if a local Ollama model is available it writes a short answer **grounded only in the
   retrieved reports, copying every number verbatim and citing each source**; otherwise the tool
   returns the exact report excerpts and their file paths. **No number is ever generated by a
   model.** This mirrors the provenance guarantee of the main platform.

## Provenance and scope

- The numbers you see are copied from the pre-computed reports; the tool retrieves and quotes, it
  does not recompute.
- All results are cross-sectional and **hypothesis-generating**; they require external validation
  and do not support causal claims.
- Steatosis is measured differently in the two surveys (KNHANES HSI vs NHANES CAP) and is never
  pooled.
